# bigskills authoring references

Copied from Matt's bigskills kit so this kit is reviewed against the same bar. They're for
whoever edits the kit, not for the skill at runtime; the skill reads `references/` only.

- `eval-rubric.md`: the 9-dimension skill rubric (used in `evals/self-assessment.md`).
- `anti-patterns.md`: the 13 failure modes to check before shipping.
- `contracts.md`: the Input / Output / Validation contract each sub-skill follows.

The kit-level grader (five criteria, Gold / Strong) lives in `vendor/bigskills/kitreview/`.
